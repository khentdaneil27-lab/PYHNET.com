Connect your real sensors

Stations without an address show demo data. To use an ESP32 water level sensor:

  1. Open the page’s CONFIG block (in the script near the bottom of this file) and set the station’s endpoint to the sensor’s data address:
{ name: "Masaba River", endpoint: "http://192.168.1.45/data" },
  1. In the ESP32 sketch, inside handleData(), add this line so the browser is allowed to read the data:
server.sendHeader("Access-Control-Allow-Origin", "*");
  1. Open this page from your computer or an http:// address on the same Wi-Fi network. A page opened over https:// cannot read an http:// sensor.
